# Changelog / Sürüm notları

This project follows [Keep a Changelog](https://keepachangelog.com/en/1.1.0/) and uses [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## 0.1.0 — 2026-09-30

### Added / Eklendi

- Direct arithmetic lookup of the digit at a positive position in the decimal Champernowne constant.
- Exact natural-position lookup and early-bird classification for targets through 1,000,000.
- Numeric-window and independently checked reconstruction engines, including early-occurrence frequencies.
- Reproducible CSV/JSON exports, manifests, checksums, benchmarks, and aggregate mathematical analyses.
- Prime, special-set, carry, finite-block, Ulam-ring, and diagonal analyses.
- Bilingual statistical figures and seven Ulam layers, with optional libpng output.
- macOS GitHub Actions checks for the core and optional PNG configuration.

### Compatibility / Uyumluluk

- The public CLI and machine-readable schemas are schema version `1`.
- Positions are one-based and exclude the initial `0.`.
- macOS with a C++20 compiler and CMake 3.20+ is the supported first-release environment.
